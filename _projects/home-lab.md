It began with a SUPER old PC that I turned into a NAS by installing TrueNAS on it. The catch? It only had 2GB of RAM… RAMageddon fr.

The original plan was to upgrade the RAM, set up Pi-hole on a Raspberry Pi borrowed from a friend, and then add Jellyfin for media hosting once the server had enough memory to handle it.
